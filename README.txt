E-KASIR TOKO KOMPLIT
====================

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder hasil ekstrak di Visual Studio Code.
3. Buka index.html menggunakan browser, atau gunakan ekstensi Live Server.
4. Aplikasi berjalan tanpa server/database eksternal. Data transaksi disimpan di localStorage browser.

Fitur:
- Dashboard penjualan, pengeluaran, laba, stok menipis.
- Kasir dengan keranjang, diskon, pajak, pembayaran dan kembalian.
- Data barang: kode, kategori, stok, stok minimum, harga beli dan harga jual.
- Pengeluaran operasional.
- Riwayat transaksi/struk.
- Cetak struk.
- Laporan penjualan, HPP, pengeluaran, laba dan produk terlaris.
- Filter laporan berdasarkan tanggal.
- Export stok CSV.
- Backup/import seluruh data JSON.
- Pengaturan identitas toko.
- Responsive untuk desktop dan layar kecil.

Catatan:
- Ini adalah aplikasi front-end. Untuk penggunaan toko nyata multi-komputer, diperlukan backend/database dan autentikasi.
- Jika transaksi dihapus, stok tidak dikembalikan otomatis.
